# TERMINAL

## QUESTIONS

- What are the top 20 commands for mac Command Line Interface (CLI)?
    1. cd (change directory)
    2. mkdir (make directory)
    3. sudo (enter password to execute a command with admin privileges)
    4. rm (remove)
    5. touch (create an empty file, or update its timestamp if it exists)
    6. open (obv)
    7. echo (like console.log for the CLI, used to print things to the output including values of variables etc.)
    8. brew (uses an install utility to run installation packages)
    9. q or ctrl+C (quits a terminal process, e.g. a localhost server)
    10. man (get the manual entry for the given command) or --help (similar)
    11. whatis (like **man**, but delivers a shorter explanation)
    12. which (followed by a command, tells you the path of that command's source code)
    13. pwd (print working directory -- tells you where you are)
    14. cp (copy file to a specified directory)
    15. mv (move file to a specified directory)
    16. cat (display the contents of a file)
    17. grep (searches for a text string within a file or files)
    18. find (searches for a file)
    19. curl (executes requests like GET or POST to a given URL)
    20. history (get list of commands you've run, can be filtered e.g. for recent git commands)
- What is a terminal? A CLI? Why are they synonymous?
    - a 'terminal' is a text-based frame for inputting commands to the computer. CLI stands for 'command line interface', which refers to the same thing: the control surface or interface from which you command actions on the local machine or across a network.
- What is the difference between bash and zsh?
    - bash is a shell environment (an intermediary or interpreter between the user and the shell's underlying code). while bash is broadly supported and feature-rich, it's less robustly featured than zsh. zsh came out more recently and provides more complex tooling, automation, and customization.
- What is the difference between Terminal, Console, Shell, and Command Line?
    - terminal: an input-output place. put text in box, make computer obey.
    - console: usually interchangeable with 'terminal', can refer to a whole collection of terminals or terminal tabs
    - shell: the specific environment the terminal/console is using, e.g. bash or zsh (the same terminal could be switched between different shell environments to interpret commands and outputs in different ways, or provide different features)
    - command line: literally the line of text where commands are typed; also refers to the whole interface, ie the terminal – as in 'open up the command line and ...'
